# APRENDIENDO GIT Y GITHUB
- Estos son los pasos para iniciar con Git
## Paso 1
- Inicializar el nuevo repositorio
```
git init
```
- Directorio de trabajo
# Paso 2

- Enviar los nuevos archivos modificados al area de preparacion
```
git add .
```
- El area de preparacion es donde se preparan los cambios 
# Paso 3
- Registrar una descripcion del cambio realizado
```
git commit -m "proyecto base"
```
------
# Paso 4 (Github)
-Crear el repositorio en Github y enlazar al proyecto
```
git remote add origin + URL
```
# Paso 5

-subimos los cambios al repositorio
```
git push origin master
```
